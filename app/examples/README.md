# Example patterns (reference only)

These 13 sketches are the patterns baked into the `SozoBasic` firmware gallery.
They live here as **references** — the Studio does **not** list them (it only
scans `../patterns/`).

To work on one, copy it into the workspace:

```bash
cp -R examples/tide patterns/tide     # from inside app/
```

Then reload the Studio and it'll appear.
